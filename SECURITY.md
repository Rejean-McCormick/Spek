# Security policy

Spek is an experimental local publishing prototype, not a validated security boundary or a scientific-certification system.

Please avoid disclosing suspected vulnerabilities publicly before the maintainer has had an opportunity to evaluate them. Use GitHub's private vulnerability reporting feature if configured; otherwise contact the repository owner through an established private channel. No response timeframe is guaranteed.

Particular areas of concern include path traversal in manifest verification, rendering injection, leaked private source data, workflow permission escalation, and bypass of publication gates. Never attach sensitive Kristal source artifacts to a public issue.

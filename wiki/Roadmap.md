# Roadmap

**0.1 (included):** Three typed layouts, FR/EN/IT output, local HTML/PDF/TeX, manifest validation, fixture SemantiK importer, CI preview and protected deployment template, English wiki.

**0.2 (delivered):** Shared SpekDocument projection, Unicode PDF handling, evidence and identifier parity, localized metadata, and pagination tests.

**0.3 (planned):** Generalized layout interpreter, authoring helpers, JSON schemas, responsive accessibility tests, and better diagnostic reports.

**0.3 (proposed):** Upstream-approved canonical identity/commitment verification, authenticated SemantiK RuntimeSet provenance, terminology checks and multilingual equivalence review records.

**0.4 (proposed):** Scientific citation formats, bibliographic metadata, JATS/Crossref/DOI-ready exports, release provenance and archives.

**Beyond:** Only after independent validation and owner authorization would production-critical use be appropriate. This document is a roadmap, not a certification statement or delivery commitment.
